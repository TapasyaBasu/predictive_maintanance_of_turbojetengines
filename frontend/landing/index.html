Workflow
How It Works

Three-stage prognostic pipeline — from raw telemetry ingestion to maintenance action directives.

📡
Step 01
Input Sensor Telemetry

Enter real-time or historical readings from 13 C-MAPSS sensor channels — temperatures, pressures, coolant flows, and efficiencies — or upload a batch CSV for fleet analysis.

🤖
Step 02
XGBoost ML Model

A gradient-boosted tree ensemble trained on 4 CMAPSS operating conditions processes the sensor vector in <15 ms. The model was tuned via grid search (RMSE ≈ 19, R² ≈ 0.96).

🔮
Step 03
RUL Prediction + Alert

The predicted RUL (in cycles) is mapped to a NOMINAL / ADVISORY / CRITICAL (AOG) status with a specific maintenance action directive shown on the dashboard gauge.
